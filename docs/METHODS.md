# Methods

Load six CSVs in memory from ZIP, audit missing values and report dates, match category rows using all shared master fields after severity decoding, check combined.csv against the category union, deduplicate annotations and retain unlabelled records.

Ten questions cover annual volume, monthly averages, event breadth, severity, categories, reasons, US firms, non-US firms, initial notification and recorded status. Monthly means use nine complete years 2013–2021, including zero-count year/month cells. Partial years are excluded from annual peak comparisons.

Figures use zero-based bars, ordered months/bands, frequency rankings, consistent classification colours and scrolling charts. Counts are product records or distinct event IDs as labelled.
